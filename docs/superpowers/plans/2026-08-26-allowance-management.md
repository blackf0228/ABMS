# 手当管理 Implementation Plan

**Goal:** 売上管理配下に、決算期の案件所属担当者別営業手当を表示する画面を追加する。

**Architecture:** 既存の `/api/sales` に決算期営業手当集計エンドポイントを追加し、契約一覧の `project_affiliation` を担当者IDとして社員マスタへ結合する。Angularは既存の単一画面コンポーネントにビュー、ナビゲーション、集計表を追加する。

**Tech Stack:** Java 21 / Spring Boot 3.5 / PostgreSQL / Angular 20 / TypeScript

**Spec:** ユーザー提示の「手当管理」要件および担当者は「案件所属」。

## Global Constraints

- 決算期は前年10月から当年9月まで。
- 技術者所属会社が「株式会社CMCソフト」以外の契約を対象とする。
- 契約有効期間は契約開始月から契約終了月までを月単位で対象とする。
- 営業手当は会社利益30,000円超の場合 `(会社利益 - 30,000) × 0.3` を小数第1位まで四捨五入し、算出値が1以下なら1とする。
